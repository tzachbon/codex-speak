Codex Speak

Select text in any Windows app, press ▶, and hear it in your ChatGPT voice. Codex Speak runs the Codex realtime voice from your ChatGPT sign-in, with no API key. Edge and offline Windows voices take over when Codex can't speak.

Download for Windows Source on GitHub Windows 11 · 64-bit · free and open source (MIT) · unofficial

What it does

Works in most apps

Drag or double-click to select text in a browser, Notepad, VS Code, and most other apps. The bar never takes focus from the app you're in.

Your ChatGPT voice

Reads with the Codex realtime voice from your ChatGPT sign-in. No API key. It uses your plan's Codex access and counts toward its limits.

Always has a voice

If Codex can't speak, Edge neural voices take over, then the offline Windows voices. You can also pin one engine.

Pause, speed, stop

Pause and continue from the same spot. Pick 0.5× to 2× from the bar. Your choice is saved.

Read-along captions

The sentence being read appears above the bar. Long sentences pan across the line. Size and background are adjustable.

Six languages

Hebrew, English, Arabic, Russian, Spanish, and French. In Auto, Codex infers the language, and Edge and Windows tell Hebrew, Arabic, and Russian apart by script. Or pick one from the menu.

Optional automatic updates

Installs new GitHub releases when the app is idle, after checking the installer's SHA-256 digest. Off by default.

Speech-to-text too

An optional local, OpenAI-compatible endpoint lets apps such as OpenWhispr transcribe with the same Codex sign-in. Details.

Get started

  1. Download the installer and run it. It installs for your user only and needs no admin rights.
    The app isn't code-signed, so Windows SmartScreen may warn you. Choose More info, then Run anyway. You can read and build the source yourself.
    Coming from Select to TTS? It's the same app under a new name. The installer replaces it and keeps your settings.
  2. For the ChatGPT voice, install the Codex CLI and sign in once with codex login. Without it, the app uses Edge and Windows voices.
  3. Select some text anywhere and press ▶. ⏸ pauses and ■ stops.
  4. Open Settings from ⚙ on the bar or from the tray icon to set speed, voice, captions, start at sign-in, and updates.

Good to know

The Codex voice is experimental

Codex's realtime API is marked experimental, and about 1 in 12 Codex reads in testing ended early or stayed silent. Silence falls back to Edge on its own.

Your clipboard is restored

Some apps, such as VS Code, hide their selection. For those the app borrows Ctrl+C and then puts back every clipboard format. You can turn this off. It's skipped in terminals.

Mouse selections only

Drag or double-click shows the bar. Keyboard selections with Shift+arrows don't.

Uninstall

Use Settings > Apps. This removes the app and its sign-in task. Your preferences stay in %APPDATA%\codex-speak.
